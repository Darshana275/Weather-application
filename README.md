# Weather-application


A simple, responsive weather web app that displays the **current weather**, **5-day forecast**, and **local time** for any city in the world using live data from APIs.
This project is developed as part of the SheCodes training workshop.

## 🚀 Features

- 🔍 Search for any city
- 🌡️ View current temperature, humidity, and wind speed
- 🗓️ See a 5-day weather forecast (with icons, max/min temp)
- 🕒 Real-time local time and day of the searched city
- 🎨 Clean UI with responsive design


## 📦 Tech Stack

- HTML5, CSS3, JavaScript
- [Axios](https://axios-http.com/) for API requests
- SheCodes Weather API  for weather data
